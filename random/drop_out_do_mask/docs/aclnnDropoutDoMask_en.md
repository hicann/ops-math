# aclnnDropoutDoMask

[📄 View source code](https://gitcode.com/cann/ops-math/tree/master/random/drop_out_do_mask)

## Supported Products

| Product                                                        | Supported|
| :----------------------------------------------------------- | :------: |
| <term>Atlas A3 training products/Atlas A3 inference products</term>    |    √     |
| <term>Atlas A2 training products/Atlas A2 inference products</term>|    √     |
| <term>Atlas 200I/500 A2 inference products</term>                     |    ×     |
| <term>Atlas inference products</term>                            |    ×     |
| <term>Atlas training products</term>                             |    √     |

## Function

Description: Zeros input elements randomly with a probability of `prob` and scales the output by `1/(1-prob)` during training. If a bit in `mask` is `1`, the corresponding input element is scaled; if a bit in `mask` is `0`, the corresponding `gradOutput` element is zeroed. Specifically, if `prob` is `0`, the `gradOutput` elements remain unchanged; if `prob` is `1`, all elements are zeroed.

$$
out_i=\begin{cases}
0,&\text { with probability }prob \\
\frac{1}{1-prob}self_i, &\text { with probability }1-prob
\end{cases}
$$

## Prototype

Each operator has [two-phase API](../../../docs/en/context/two_phase_api.md) calls. First, `aclnnDropoutDoMaskGetWorkspaceSize` is called to obtain the workspace size required for computation and the executor that contains the operator computation process. Then, `aclnnDropoutDoMask` is called to perform computation.

- `aclnnStatus aclnnDropoutDoMaskGetWorkspaceSize(const aclTensor* self, const aclTensor* mask, double prob, aclTensor* out, uint64_t* workspaceSize, aclOpExecutor** executor)`
- `aclnnStatus aclnnDropoutDoMask(void *workspace, uint64_t workspaceSize, aclOpExecutor *executor, aclrtStream stream)`

## aclnnDropoutDoMaskGetWorkspaceSize

- **Parameters**

  - `self` (aclTensor\*, computation input): input `self` in the formula. The shape must be 0D to 8D. [non-contiguous tensor](../../../docs/en/context/non_contiguous_tensor.md) are supported. The [data format](../../../docs/en/context/data_format.md) can be ND.
    - <term>Atlas training products</term>: The data type can be FLOAT or FLOAT16.
    - <term>Atlas A2 training products/Atlas A2 inference products</term> and <term>Atlas A3 training products/Atlas A3 inference products</term>: The data type can be FLOAT, FLOAT16, or BFLOAT16.
  - `mask` (aclTensor\*, computation input): bitmask data stored as UINT8. The data type can be UINT8. The shape must be 1D to 8D. The shape must be (`align`(number of elements in `self`, 128)/8), indicating that the number of bits must be aligned with 128. `align` indicates that the number of elements in the input is rounded up to a multiple of 128. For example, the result of align (1111, 128) is 1152. [non-contiguous tensor](../../../docs/en/context/non_contiguous_tensor.md) are supported. The [data format](../../../docs/en/context/data_format.md) can be ND.
  - `prob` (double, computation input): input `prob` in the formula, which is used to calculate the output data scaling ratio.
  - `out` (aclTensor*, computation output): output tensor, `out` in the formula. The data type must be convertible from that of `self`. The shape must be identical to that of `self`. [non-contiguous tensor](../../../docs/en/context/non_contiguous_tensor.md) are supported. The [data format](../../../docs/en/context/data_format.md) can be ND.
    - <term>Atlas training products</term>: The data type can be FLOAT or FLOAT16.
    - <term>Atlas A2 training products/Atlas A2 inference products</term> and <term>Atlas A3 training products/Atlas A3 inference products</term>: The data type can be FLOAT, FLOAT16, or BFLOAT16.
  - `workspaceSize` (uint64_t*, output): size of the workspace to be allocated on the device.
  - `executor` (aclOpExecutor**, output): operator executor, containing the operator computation process.

- **Returns**

  `aclnnStatus`: status code. For details, see [aclnn Return Code](../../../docs/en/context/aclnn_return_code.md).

  ```text
  The first-phase API implements input parameter validation. The following error codes may be returned:
  161001 (ACLNN_ERR_PARAM_NULLPTR): 1. The passed self, mask, or out is a null pointer.
  161002 (ACLNN_ERR_PARAM_INVALID): 1. The data type of self, mask, or out is not supported.
                                    2. The value of prob is not between 0 and 1.
                                    3. The shapes of self and out are inconsistent.
                                    4. The shape of mask does not meet the requirements.
  ```

## aclnnDropoutDoMask

- **Parameters**

  - `workspace` (void*, input): address of the workspace to be allocated on the device.
  - `workspaceSize` (uint64_t, input): size of the workspace to be allocated on the device, which is obtained by calling the first-phase API `aclnnDropoutDoMaskGetWorkspaceSize`.
  - `executor` (aclOpExecutor*, input): operator executor, containing the operator computation process.
  - `stream` (aclrtStream, input): stream for executing the task.

- **Returns**

  `aclnnStatus`: status code. For details, see [aclnn Return Code](../../../docs/en/context/aclnn_return_code.md).

## Constraints

- Deterministic computation:
  - `aclnnDropoutDoMask` defaults to a deterministic implementation.
