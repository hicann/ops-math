# aclnnInplaceZero

[📄 View source code](https://gitcode.com/cann/ops-math/tree/master/math/zero_op)

## Supported Products

| Product                                                        | Supported|
| :----------------------------------------------------------- | :------: |
| <term>Atlas A3 training products/Atlas A3 inference products</term>    |    √     |
| <term>Atlas A2 training products/Atlas A2 inference products</term>|    √     |
| <term>Atlas 200I/500 A2 inference products</term>                     |    ×     |
| <term>Atlas inference products</term>                            |    √     |
| <term>Atlas training products</term>                             |    √     |

## Function

- Operator function: Fills the `selfRef` tensor with all zeros.

- Formula:

  $$
    {selfRef}_{i} = 0
  $$

- Example:

  ```text
  Input selfRef:
  tensor([[1, 2],
          [3, 4]])
  Output selfRef:
  tensor([[0, 0],
          [0, 0]])
  ```

## Prototype

Each operator has [two-phase API](../../../docs/en/context/two_phase_api.md) calls. First, `aclnnInplaceZeroGetWorkspaceSize` is called to obtain the input parameters and compute the required workspace size based on the process. Then, `aclnnInplaceZero` is called to perform computation.

- `aclnnStatus aclnnInplaceZeroGetWorkspaceSize(aclTensor *selfRef, uint64_t *workspaceSize, aclOpExecutor **executor)`
- `aclnnStatus aclnnInplaceZero(void *workspace, uint64_t workspaceSize, aclOpExecutor *executor, aclrtStream stream)`

## aclnnInplaceZeroGetWorkspaceSize

- **Parameters**:

  - `selfRef` (aclTensor*, compute input | compute output): `selfRef` in the formula, aclTensor on the device. [non-contiguous tensor](../../../docs/en/context/non_contiguous_tensor.md) are supported. The [data format](../../../docs/en/context/data_format.md) supports ND.
    - <term>Atlas inference products</term> and <term>Atlas training products</term>: The data type can be INT8, INT32, INT64, UINT8, FLOAT16, FLOAT32, BOOL, DOUBLE, INT16, UINT16, COMPLEX128, or COMPLEX64.
    - <term>Atlas A2 training products/Atlas A2 inference products</term> and <term>Atlas A3 training products/Atlas A3 inference products</term>: The data type can be INT8, INT32, INT64, UINT8, FLOAT16, FLOAT32, BOOL, DOUBLE, INT16, UINT16, COMPLEX128, COMPLEX64, or BFLOAT16.
  - `workspaceSize` (uint64_t\*, output): size of the workspace to be allocated on the device.
  - `executor` (aclOpExecutor\**, output): operator executor, containing the operator computation process.

- **Returns**:

  `aclnnStatus`: status code. For details, see [aclnn Return Code](../../../docs/en/context/aclnn_return_code.md).

  ```text
  The first-phase API implements input parameter verification. The following errors may be thrown.
  161001 (ACLNN_ERR_PARAM_NULLPTR): 1. The passed `selfRef` is a null pointer.
  161002 (ACLNN_ERR_PARAM_INVALID): 1. The data type of `selfRef` is not supported.
  ```

## aclnnInplaceZero

- **Parameters**:

  - `workspace` (void\*, input): address of the workspace to be allocated on the device.
  - `workspaceSize` (uint64_t, input): size of the workspace to be allocated on the device, which is obtained by calling aclnnInplaceZeroGetWorkspaceSize.
  - `executor` (aclOpExecutor\*, input): operator executor, containing the operator computation process.
  - `stream` (aclrtStream, input): stream for executing the task.

- **Returns**:

  `aclnnStatus`: status code. For details, see [aclnn Return Code](../../../docs/en/context/aclnn_return_code.md).

## Constraints

- Deterministic computation:
  - `aclnnInplaceZero` defaults to a deterministic implementation.
