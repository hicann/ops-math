# aclnnGeTensor&aclnnInplaceGeTensor

[📄 View source code](https://gitcode.com/cann/ops-math/tree/master/math/greater_equal)

| <term>Atlas training products</term>                             |    √     |

## Function

- Function: Checks whether each element in the input tensor is greater than or equal to the corresponding element in the other tensor. A tensor of the bool type is returned, indicating whether the condition is met for each element in the input tensor.

- Formula:
  For the input parameters `self` and `other`, `ge` can be expressed by the following formula:

  $$
  out_{i}= (self_i >= other_i) ? True : False
  $$

## Prototype

Each operator has [two-phase API](../../../docs/en/context/two_phase_api.md) calls. First, `aclnnGeTensorGetWorkspaceSize` or `aclnnInplaceGeTensorGetWorkspaceSize` is called to obtain the workspace size required for computation and the executor that contains the operator computation process. Then, `aclnnGeTensor` or `aclnnInplaceGeTensor` is called to perform computation.

```Cpp

  const aclTensor*  self,
  const aclTensor*  other,
  aclTensor*        out,
  uint64_t*         workspaceSize,
  aclOpExecutor**   executor)
```

                    aclDataType dataType, aclTensor** tensor) {
  auto size = GetShapeSize(shape) * sizeof(T);
  // Call aclrtMalloc to allocate memory on the device.

  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMalloc failed. ERROR: %d\n", ret); return ret);
  // Call aclrtMemcpy to copy the data on the host to the memory on the device.
  ret = aclrtMemcpy(*deviceAddr, size, hostData.data(), size, ACL_MEMCPY_HOST_TO_DEVICE);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMemcpy failed. ERROR: %d\n", ret); return ret);

  // Compute the strides of the contiguous tensor.
  std::vector<int64_t> strides(shape.size(), 1);
  for (int64_t i = shape.size() - 2; i >= 0; i--) {
    strides[i] = shape[i + 1] * strides[i + 1];
  }

  // Call aclCreateTensor to create an aclTensor.
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
